QUICK START
1. Read the description for the batch file you want.
2. Save ONE .bat file into a folder containing the files to process.
3. Double-click the .bat file on a Windows 10 or Windows 11 computer.
4. Read the terminal messages and inspect the newly created output folder or CSV report.

IMPORTANT
- These scripts operate on the folder where you put the .bat file, NOT folders
  chosen by a file-picker. Most scan only that folder. Inventory and duplicate
  reports explicitly scan subfolders too.
- The tools are designed NOT to overwrite or delete originals. If the named
  output file already exists, the script skips it.
- Make your own backups. Test with copies of files before using any workflow
  for commercial deliveries.
- Audio/video scripts require FFmpeg installed and available in PATH. The
  package DOES NOT bundle, install or download FFmpeg.
- Other scripts use Windows PowerShell, normally included with Windows 10/11.
- Text cleaners expect UTF-8 TXT or Markdown. They DO NOT work with DOCX.
- These are simple utilities, not certified mastering or audiobook compliance
  tools. A report or conversion does not mean your files meet distributor specs.
- Review any downloaded .bat file before running it. Do NOT disable Windows
  security protection to run downloaded code. No administrator access required.
- No network requests, telemetry, trackers, installer or automatic updates.
- These are a preliminary release. Native Windows execution still needs testing.
