How it works

  1. Choose the correct .bat file for your task.
  2. Put it in a Windows folder containing the input files.
  3. Double-click. Read the console messages and inspect the new output folder or CSV report.

The audio and video tools need FFmpeg installed and available in PATH. The text, image and file reports use Windows PowerShell.

Safety and limitations

The scripts are designed to preserve source files and skip existing output files. Still, always test on disposable copies before working with client material.

These are early tools, not yet Windows-tested across machines. They do not certify audiobook quality or platform compliance. Inspect the readable source before you run a downloaded batch file, and never disable Windows security to bypass a warning.
